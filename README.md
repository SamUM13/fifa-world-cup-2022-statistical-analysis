# Statistical Analysis and Probabilistic Modeling of FIFA World Cup 2022 Player Performance
This project applies statistical analysis and probability theory to investigate player performance patterns during the FIFA World Cup 2022.

Using a dataset containing 814 players and 18 attributes, the analysis explores player performance, statistical distributions, relationships between player characteristics, and the probability of scoring based on playing position.

The project demonstrates practical applications of descriptive statistics, exploratory data analysis, statistical inference, Bayesian reasoning, Monte Carlo simulation, and probability distribution fitting using Python.
